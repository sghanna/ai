# Spades

A partnership card game for one person and three computer players, prepared for review at [sghanna.github.io/ai/games/spades/](https://sghanna.github.io/ai/games/spades/).

After reviewing Euchre, Shawn requested the same approach for Spades: AGY collaboration, the established card-game design, and publication for review. This game carries forward his requirements for readable cards, slow presses, modest finger drift, and changing a selection before confirming.

## At the table

You and Partner play against West and East. Each player receives thirteen cards. Use the large bid controls to choose a numbered bid or Nil, then confirm. Tap a card and press Play to commit it. Every completed trick waits for you to continue. Menu pauses the computer players; Last trick and the bid summary remain available.

The table shows each player's bid and tricks, team contracts, accumulated bags and match scores. Nil failures are labeled immediately. A two-row hand keeps rank and suit visible, including while changing a selection. Small windows can scroll without reducing the controls.

This version uses a standard 52-card deck with aces high and spades always trump. Bidding and the first lead start to the dealer's left. Follow suit when possible; a spade may be played on the first trick when void in the led suit. Spades cannot be led until broken unless the hand contains only spades.

House rules are explicit in Help:

- Numbered bids are 1-13; zero is Nil. Each player bids once. Partners combine numbered bids.
- A made contract earns ten times the bid, plus one point per overtrick. A set contract loses ten times the bid.
- Extras are bags. Every ten accumulated bags cost 100 points; excess bags carry forward.
- Nil earns or loses 100 independently of the partner's contract. Failed Nil tricks do not satisfy that contract; each adds one bag and one bag point, even when the partner is set. Two Nil bids are scored independently.
- All thirteen tricks are scored before checking the target. The higher total wins if both teams reach it; equal totals continue another hand. There is no negative-score knockout.
- The default target is 500; Settings offers 250 for the next match. No blind Nil, jokers, passing or special double-Nil bonus.

Rules references: [Pagat's basic partnership Spades](https://www.pagat.com/auctionwhist/spades.html) and [Bicycle](https://bicyclecards.com/how-to-play/spades/), consulted September 30, 2026. The choices above define this implementation where house rules differ.

## Save and install

Progress and selections save on this browser, with an earlier position retained for recovery. Load the game online once to prepare its offline copy. Safari's Share menu offers Add to Home Screen. Clearing website data removes progress. The game has no advertisements, analytics, account requirement, external fonts or runtime packages.

Computer players use simple bidding and play heuristics, including avoiding tricks on Nil and trying to cover a partner's Nil. They see their own cards and public play only. Expert-level play is not claimed.

## Source and checks

Canonical source: `~/codex/spades/`. Public deployment: `games/spades/` in `sghanna/ai`. Release cache: `ai-spades-v1`. Copy only the release files from the canonical source; publication requires Shawn's instruction.

```sh
npm ci
npm test
python3 -m http.server 8798 --bind 127.0.0.1
# In another terminal, with Playwright browsers installed:
npm run test:browser
# Uses the fixtures generated by test:browser:
npm run test:activation
```

The browser harness uses desktop WebKit and installed Chrome. `WEBKIT_PATH` selects an existing WebKit executable; `CHROME_CHANNEL` and `SPADES_URL` can select another Chrome channel or test URL. `TOUCH_ONLY=1` runs the native touch and offline checks. Local artifacts go in ignored `output/playwright/`.

Eleven engine test groups cover dealing, bidding, following suit, spade restrictions, nil scoring, bags, target ties, hidden-hand boundaries, save replay and 200 complete deterministic matches. Browser verification covers 99 game-state/viewport combinations, a complete match through the visible controls, selection changes, reload/rotation, settings, keyboard use, save recovery and offline loading. Eighteen additional mouse, keyboard and touch checks cover repeated activation across the changing primary button and a later deliberate retry. Native Chromium checks use real 6.5-second holds and cover drift, cancellation, extra fingers and clicks after closing a dialog. [Verification record](verification.json) contains the completed checks.

Physical iPhone/iPad play, Safari toolbars, home-screen installation, pinch zoom, VoiceOver and the player's natural gestures remain untested. Desktop automation is supporting evidence for the review build.

Saves use `ai-spades-game-v1` and its `-backup`; settings use `ai-spades-settings-v1`. The worker owns only `ai-spades-` caches and its own directory scope. Bump its cache version and matching asset URL versions together for future releases. Updates wait for existing game tabs to close.
